Copyright (C) 2026 RiskDataScience GmbH. Licensed under GPL-3.0-only.

Community support is provided on a best-effort basis through GitHub issues at
<https://github.com/rds0001/risk-weighted-assets/issues>.

Before opening an issue, run the automated tests and release validator, then include the
software version, Python version, operating system, command used, concise reproduction
steps and sanitized error output. Never attach confidential or personal data.

Questions that require institution-specific regulatory interpretation, validation,
implementation assurance or production support are outside the scope of community support.
